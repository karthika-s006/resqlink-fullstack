# ResQLInk Frontend

The React/Vite client uses the ResQLInk REST API. From this folder, run `npm install` and `npm run dev`. Copy `.env.example` to `.env` only when the API is not at `http://localhost:5000/api`.

Vite uses port 5173 by default and automatically selects 5174 if 5173 is occupied. The backend allows both ports for local development.

See the [project README](../README.md) for MongoDB setup, backend startup, environment configuration, and API details.
